**# Odin HTML Fundamentals Practice Project**  
   
**Welcome to the **Odin HTML Fundamentals Practice Project**! The main aim of this project is to put into practice what has been learned from The Odin Project's HTML Foundations course.**  
**## Objectives**  
**This project focuses on applying the following HTML Foundations concepts:**  
   
**1. **Introduction to HTML and CSS** — understanding the basic relationship between HTML and CSS.**  
**2. **Elements and Tags** — using various HTML elements and tags to structure content.**  
**3. **HTML Boilerplate** — setting up the basic document structure for each page.**  
**4. **Working with Text** — formatting and organizing text content properly.**  
**5. **Lists**:**  
**   - *Unordered lists* — used to list the ingredients for each recipe.**  
**   - *Ordered lists* — used to outline the step-by-step instructions for preparing each dish.**  
**6. **Links and Images**:**  
**   - **Anchor elements** — used to connect pages internally through relative links.**  
**   - **Void elements** — used to instruct the browser to display images on the recipe pages.**  
**7. **Commit Messages** — writing clear and meaningful Git commit messages throughout development.**  
**8. **Project: Recipes** — bringing all the above concepts together to build a basic multi-page recipe website.**  
   
**## Technologies Used**  
   
**- **GitHub** — for hosting and version control of the repository.**  
**- **Git** — for tracking changes and managing project history.**  
**- **Linux Command Line** — for navigating the file system and running Git commands.**  
**- **VS Code** — as the code editor for writing and organizing HTML files.**  
**- **Firefox Browser** — for viewing and testing the website locally.**
